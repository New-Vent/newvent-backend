# 오류 코드

**이 표는 손으로 유지하지 않습니다.** 코드의 `*ErrorCode` enum 에서 뽑은 것입니다.
바뀌면 아래로 다시 뽑으세요. **`grep` 으로는 안 됩니다** — 선언이 여러 줄에 걸쳐 있어
한 줄짜리 정규식이 절반을 놓칩니다 (실제로 처음 작성할 때 16개를 빠뜨렸습니다).

```bash
python3 - <<'PY'
import re, pathlib
pat = re.compile(r'HttpStatus\.([A-Z_]+)\s*,\s*"([A-Z_]+[0-9]{3}-[0-9]+)"\s*,\s*"((?:[^"\\]|\\.)*)"', re.S)
for p in sorted(pathlib.Path('src/main/java').rglob('*ErrorCode.java')):
    for st, code, msg in pat.findall(p.read_text()):
        print(f"| `{code}` | {st} | {' '.join(msg.split())} |")
PY
```

코드 체계와 `ErrorCode` 인터페이스는 [`api-conventions.md`](api-conventions.md) §4 를 보세요.

> **클라이언트는 `code` 로 분기합니다.** `message` 는 사람이 읽는 문구라 바뀔 수 있고,
> HTTP 상태만으로는 같은 409 안에서 무엇이 문제인지 구별할 수 없습니다.

| `COMMON403-0` | 403 | 접근 권한이 없습니다 |
| `COMMON404-0` | 404 | 요청한 경로를 찾을 수 없습니다 |

> `.anyRequest().authenticated()` 가 먼저 걸리기 때문입니다. 오타를 디버깅할 때 헷갈립니다.

## 인증 (`auth/`)

| 코드 | 상태 | 의미 |
| --- | --- | --- |
| `AUTH401-0` | 401 | 아이디 또는 비밀번호가 올바르지 않습니다 |
| `AUTH401-1` | 401 | 유효하지 않은 Refresh Token 입니다 |
| `AUTH403-0` | 403 | 요청 출처를 확인할 수 없습니다 |

`AUTH403-0` 은 `CsrfOriginFilter` 가 냅니다. **`POST` 인증 경로에만** 걸리고, `Origin`
(없으면 `Referer`)이 `auth.cors.allowed-origins` 에 없으면 거부합니다. curl 로 로그인을
테스트할 때 `Origin` 헤더를 빠뜨리면 이게 나옵니다.

| `EVENT409-9` | 409 | 참여 기록이 있는 이벤트는 영구 삭제할 수 없습니다. 참여한 사용자의 참여·당첨 기록이 함께 사라지기 때문입니다 |

**`EVENT404-0` 과 `EVENT404-2` 의 차이** — 전자는 없거나 삭제됐거나 아직 게시 전,
후자는 공개 기간 밖입니다. 둘 다 404 인 이유는 [`api-design.md`](api-design.md) §4.

`EVENT409-8` 은 **게시 시각에 종료일시가 이미 지난** 경우입니다 (종료 시각과 같은 순간도 포함).
시작일은 검사하지 않습니다 — 진행 중 이벤트의 재게시도, 시작 전 이벤트의 예약 게시도 됩니다.
막는 이유는 게시하는 순간 자동 종료 스케줄러가 바로 `ENDED` 로 바꿔 수정·재게시가 잠기기 때문입니다.

`EVENT409-9` 는 **영구 삭제(`DELETE /api/admin/events/{id}/permanent`)** 에서만 납니다.
검사 순서는 휴지통에 없음(404) → 만든 관리자가 아님(403) → 참여 기록 있음(409) 입니다.
휴지통으로 보내기와 복구는 참여 기록과 무관하게 됩니다. 이유는 [`api-design.md`](api-design.md) §7.

## 페이지 생성 (`generation/`)

| 코드 | 상태 | 의미 |
| --- | --- | --- |
| `GEN400-0` | 400 | 요청 내용을 입력해 주세요 |
| `GEN400-1` | 400 | 요청이 너무 깁니다 |
| `GEN400-2` | 400 | 선택한 템플릿을 찾을 수 없습니다. 템플릿을 다시 골라 주세요 |
| `GEN400-3` | 400 | 템플릿으로 만들기와 AI로 만들기 중 하나만 골라 주세요 |
| `GEN404-0` | 404 | 해당 작업을 찾을 수 없습니다. 이미 끝났거나 오래된 작업입니다 |
| `GEN404-1` | 404 | 아직 만들어진 페이지가 없습니다 |
| `GEN404-2` | 404 | 중단할 작업이 없습니다. 이미 끝났을 수 있습니다 |
| `GEN409-0` | 409 | 이미 생성이 진행 중입니다. 잠시 후 다시 시도해 주세요 |
| `GEN409-1` | 409 | 종료된 이벤트는 페이지를 새로 만들 수 없습니다 |

`GEN400-3` 은 `templateCode` 와 `requestText` 를 **같이** 보냈을 때입니다. 템플릿으로 가면
모델을 안 부르므로 요청문이 조용히 버려지고 `DONE` 으로 끝납니다 — 그걸 성공으로
보이게 하지 않으려고 아예 거절합니다. AI 생성이면 `templateCode: ""`, 템플릿이면
`requestText` 를 비우세요. **`templateCode` 를 안 보내도 이벤트에 붙은 템플릿이 쓰이므로**
그것만으로는 AI 생성이 되지 않습니다.

> `GEN404-1` 과 `EDIT404-0` 은 문구가 거의 같지만 **다른 코드**입니다. 전자는 미리보기
> 조회(`GenerationPreviewController`), 후자는 채팅 수정 시작입니다. `message` 로 분기하면
> 둘이 섞입니다.

`GEN409-0` 과 `EDIT409-0` 은 **같은 자리를 놓고 다툰 결과**입니다. 생성과 채팅 수정이
`jobs.start(eventId)` 하나를 공유하므로, **어느 코드가 나오는지는 무엇이 돌고 있었는지가
아니라 어느 API 를 불렀는지로 정해집니다.** 생성이 도는 중에 채팅 수정을 누르면
`GEN409-0` 이 아니라 `EDIT409-0` 이 옵니다.

## 채팅 수정 (`editor/`)

| 코드 | 상태 | 의미 |
| --- | --- | --- |
| `EDIT400-0` | 400 | 고를 수 없는 영역입니다. 유의사항은 채팅으로 고칠 수 없습니다 |
| `EDIT404-0` | 404 | 아직 만들어진 페이지가 없습니다. 먼저 페이지를 만들어 주세요 |
| `EDIT409-0` | 409 | 이 이벤트에 진행 중인 작업이 있습니다. 끝난 뒤 다시 시도해 주세요 |

`EDIT400-0` 과 `ROUTER400-2` 는 둘 다 "그 영역은 못 고친다" 지만 **순서가 반대**입니다.

- `EDIT400-0` — 프론트가 **직접 보낸** `blocks` 가 레지스트리에 없거나 채팅 수정 대상이
  아닙니다. **모델을 부르기 전에** 거릅니다 (`EditService` ②-b). 프론트가 고를 수 있는 것만
  보내야 하므로, 여기까지 오면 프론트 버그입니다.
- `ROUTER400-2` — `blocks` 없이 자연어만 보내서 **모델이 영역을 알아낸 뒤**, 그게 못 바꾸는
  영역일 때입니다. 관리자 잘못이 아니라 되묻기로 끝납니다.
