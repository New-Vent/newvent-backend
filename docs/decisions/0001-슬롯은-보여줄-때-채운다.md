# 0001. 슬롯은 저장할 때가 아니라 보여줄 때 채운다

- 상태: 적용됨
- 관련 코드: `registry/Slots.java` · `registry/Slot.java` · `event/service/PublicEventService.java`

## 문제

이벤트 페이지 HTML 에는 **서버만 아는 값**이 들어갑니다. 기간과 참여 링크입니다.

```html
<p data-slot="period">2026.09.22 ~ 10.06</p>
<button data-slot="cta-link">응모하기</button>
```

LLM 이 만든 HTML 을 저장할 때 이 값을 함께 박아 넣을 수도 있고, 저장은 빈 채로 하고
내보낼 때 채울 수도 있습니다.

## 결정

**빈 채로 저장하고, 보여줄 때 채웁니다.**

```java
// 저장: 슬롯 태그만 있고 값은 없다
<p data-slot="period"></p>

// 내보낼 때: Slots.fill(html, PeriodText.of(start, end), ctaUrl)
<p data-slot="period">2026.09.22 ~ 10.06</p>
```

## 이유

**저장할 때 채우면 그 값이 굳습니다.** 관리자가 이벤트 기간만 수정해도 화면이 안 바뀝니다.
HTML 안에 옛 날짜가 그대로 남아 있기 때문입니다.

고치려면 기간을 바꿀 때마다 저장된 모든 버전의 HTML 을 다시 써야 합니다. 버전은 이력이라
**과거 버전을 수정하는 것은 이력의 의미를 깨뜨립니다.**

## 결과

**좋은 점**

- 이벤트 폼(기간·링크)과 HTML 이 한 방향으로만 흐릅니다. 폼이 원본이고 HTML 은 표현입니다
- 버전 이력이 "그때 LLM 이 만든 것" 그대로 남습니다

**치러야 하는 비용**

- HTML 을 내보내는 **모든 경로**가 `Slots.fill` 을 거쳐야 합니다. 빠뜨리면 슬롯이 빈 채로
  나가고, 화면에는 날짜 자리가 **비어 보입니다**
- 실제로 공개 상세 API 에서 한 번 빠뜨린 적이 있습니다 (PR #112 에서 수정)

**그래서 엔티티에서 직접 꺼내면 안 됩니다.**

```java
// ❌ 슬롯이 빈 채로 나간다
event.getPublishedVersion().getHtmlContent()

// ✅
publicEventService.publishedHtmlOf(event)
ThumbnailHtml.of(event, html)
```

## 비고

`Slot.Kind` 가 `TEXT` 와 `LINK` 로 갈립니다. 채우는 법도 비우는 법도 다릅니다.

```
TEXT  태그 안의 글자를 채운다. 비울 때 글자를 지운다
LINK  href / data-href 속성을 채운다. 비울 때 **속성만** 지운다
```

`LINK` 에서 내용을 지우면 안 됩니다. `<button data-slot="cta-link">쿠폰팩 받기</button>` 의
글자는 슬롯 값이 아니라 **CTA 라벨**이라, 지우면 빈 버튼이 됩니다.
