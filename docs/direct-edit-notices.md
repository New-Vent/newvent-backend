# 관리자 유의사항 직접 편집

- 기존 `POST /api/admin/events/{eventId}/versions/direct-edit`를 사용한다.
- 미리보기 `editableTexts`에는 `notices` 안의 문구도 문서 순서로 포함한다.
- 프론트는 서버가 반환한 `index`와 `before`로 문구를 변경한다.
- 요청·응답 DTO와 DB 스키마는 변경하지 않는다.
- 유의사항도 줄바꿈·빈 문자열·재입력을 허용하며 HTML 입력은 이스케이프한다.
- 직접 편집한 유의사항은 새 버전, 미리보기, 게시본과 등록 템플릿에 남는다.
- 유의사항이 없는 초기 페이지에는 기존 기본 문구를 넣는다.
- AI 채팅의 유의사항 수정·삭제 제한과 블록 순서 고정은 유지한다.
- 유의사항 문구 편집은 실제 참여 제한·추첨 설정을 변경하지 않는다.

편집 목록에 유의사항이 추가되므로 이후 문구의 인덱스가 달라질 수 있다.
백엔드와 프론트를 함께 반영하고 기존 편집 화면은 새로고침하여 기준 목록을 다시 받는다.
