## 실패 패턴 분석

### negative 문항: 모델별 편차가 큼

"아무것도 안 나오면 정답"인데 모델마다 다르게 실패한다.
titan만 5개 전부 통과하는데, titan은 반대로 일반 문항을 21개나 틀린다
(보수적이라 안 뱉는 쪽으로 치우침). negative는 모델 실력보다
거리 컷(0.5) 설정 문제다.

| 모델 | negative 실패 | 통과 |
|---|---|---|
| bge-m3 | 4개 (유의사항, xyz123, 당첨자발표일, 문의처) | 주식 |
| cohere | 3개 (유의사항, 당첨자발표일, 문의처) | xyz123, 주식 |
| titan | 0개 | 5개 전부 |

### cta 쏠림

"참여", "쿠폰 받기" 같은 2~5글자 짧은 cta 청크가 시드마다 반복돼서
짧은 쿼리("참여 방법", "할인 쿠폰")의 상위권을 싹쓸이한다.
모호한 질문 7개는 구체형으로 바꿨다 (예: "참여 방법" → "참여 절차를 순서대로 알려줘").
그래도 안 되는 건 시드 문구 쪽 문제로 보고 개별 손본다.

### 모델별 특이

- bge-m3: negative 4개 실패. 일반 문항은 가장 고름
- cohere: negative 4개 실패 (xyz123은 통과). 일반 문항은 bge와 동점
- mxbai/titan/snowflake: 일반 문항 탈락이 많아 운영 후보에서 제외

### 신규 엣지 문항 (40종 교체분)

- "장기가입 지원금 차감 방식"(intro): cohere만 통과. bge는 hero·cta만 반환하고 분할된 intro 청크를 못 건졌다
- "기본형과 무제한형 요금제는 뭐가 달라?"(compare): cohere만 통과. 구 문항("A형과 B형") 교체 효과 확인
- "친구 초대 적립 한도"(faq): 레이아웃 개편 전에는 cohere 통과, 개편 후 실패로 바뀜.
  새로 넣은 intro("초대 안내…적립됩니다")가 faq("적립 한도가 있나요?")를 밀어내고 상위권을 차지했다.
  답이 되는 내용은 그대로 있으니 품질 저하가 아니라 평가 엄밀성(블록 일치) 문제다. 문항 손질은 안 한다

## 중요 발견: cohere 측정 오염 (여전함)

cohere·bge 상위권에 시드 40종에 없는 청크가 섞여 나온다
("Event Benefits 🎁 데이터 10GB", "How to Join 참여 방법",
"선착순 플래시 특가 ⚡", "🌙 한가위 특별 혜택" 등).
원인: dev DB에 옛 시드·실데이터 청크가 남아 있고,
평가가 같은 내용을 또 색인해서 중복·혼입 집계됐다.
이전 대응(빈 DB 재측정)은 이번에도 안 됐다.

영향: 오염 청크가 top-3 자리를 먹어서 점수는 저평가 쪽으로 기운다.
그럼에도 cohere 33/40으로 게이트를 넘었다.

## 결론

- 게이트(30/40) 통과. cohere 32로 단독 1위 (bge 30은 턱걸이)
- 레이아웃 개편으로 cohere 33→32, titan 15→14. 둘 다 새로 넣은 블록이 기존 청크를 밀어낸 자리다툼이다.
  titan 쪽("자정까지 반짝세일" hero→highlight 밀림)은 탈락 모델이라 무시한다.
  cohere 쪽("친구 초대" faq→intro 밀림)은 답 내용이 그대로라 품질 저하가 아니다
- **cohere 유지** 확정. 교체 명분 없음
- 단 오염 상태 측정이라, 깨끗한 DB에서 재측정 후 최종 확정한다
